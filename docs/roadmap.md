# CareerMatch AI Roadmap

## Phase 1: Core Functionality (Current)

- [x] Resume parsing (PDF, DOCX, TXT, MD)
- [x] LLM-based ATS scoring
- [x] Gap analysis and recommendations
- [x] Bullet point rewriting
- [x] Company profile matching (9 Indian IT companies)
- [x] Streamlit frontend UI
- [x] FastAPI backend with authentication
- [x] Docker Compose setup

## Phase 2: Testing & Quality

- [ ] Unit tests for domain services
- [ ] Integration tests for API endpoints
- [ ] Mock LLM responses for testing
- [ ] CI/CD pipeline with coverage checks
- [ ] Code linting and type checking

## Phase 3: Enhanced Features

- [ ] Job description matching
- [ ] Resume version comparison
- [ ] Batch analysis for multiple resumes
- [ ] Export to PDF format
- [ ] Resume templates and suggestions

## Phase 4: Production Readiness

- [ ] Redis caching for LLM responses
- [ ] Rate limiting on API endpoints
- [ ] File storage optimization (S3 integration)
- [ ] Monitoring and logging
- [ ] Performance optimization

## Phase 5: Advanced Features

- [ ] Vector similarity search with pgvector
- [ ] Resume-job matching score
- [ ] Career path recommendations
- [ ] Integration with job boards
- [ ] Mobile-responsive UI

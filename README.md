# AI Resume Job Match Analyzer

An AI-powered NLP application that analyzes resumes against job descriptions using semantic similarity, skill extraction, and ATS-style scoring.

---

## Features

- Resume PDF Parsing
- Skill Extraction
- Resume vs Job Description Matching
- Semantic Similarity Analysis
- ATS-style Resume Evaluation
- Modular NLP Pipeline

---

## Tech Stack

- Python
- NLP
- Sentence Transformers
- Scikit-learn
- PDF Parsing
- Cosine Similarity
